In this lesson: **colours** and how they **match** the noun they describe.

## Colour endings

| | ending | example |
|---|---|---|
| masculine | ‑ы | **Мой сабака чорны.** |
| feminine | ‑ая | **Мыш белая.** |
| neuter | ‑ае | **Сонца жоўтае.** |
| plural | ‑ыя | **Кветкі чырвоныя.** |

**сіні** (blue) has soft endings:

- **Неба сіняе.** — The sky is blue.
- **Мае вочы сінія.** — My eyes are blue.

## As the object

After a verb like "have", "carry" or "like", the feminine ending is ‑ую:

- **Дзяўчына нясе белую сукенку.** — The girl is carrying a white dress.
- **Ён мае аранжавую сумку.** — He has an orange bag.
- **Я люблю чырвоны колер.** — I like the red color.

> **Watch out:** **мыш** ends in a consonant but it is feminine, so it's **Мыш белая**.
