# Upper Sorbian: unsure / not fixed

All items of the first proofread were resolved on 2026-10-19 against soblex (soblexx.de, the Sorbian
Institute's dictionary). What is left needs a native speaker:

## Not settled by a dictionary
- *sydomtysacty* (seven thousandth) is built by analogy with the attested *pjećtysacty*; no dictionary entry.
- Clock times now read *w / we* + ordinal + *hodźinje* (DOW: "w sedmej hodźinje"). *we wosmej* uses the w→we rule
  before *w-*; a native check of *we wosmej hodźinje* would settle it. Everyday speech uses *w dwěmaj* etc.

## Noticed while checking, not on the original list (left alone)
- Conditional skill: forms like *bysy*, *Jeli bysy ty słysał, to woni bychu byli ćichi* look garbled.
- *To je lěpši* / *běše lěpši* use the adjective where the adverb *lěpje* is expected.
- *Kudaž jězdźi tón ćah?* (question word should be *Hdźe* / *Kak*?), *Prašam jich za dróhu* (prašeć is reflexive:
  *prašam so*), *Kupc so praša wo cenu* (preposition), *Wona kaže psej* = "She says to the dog" (kazać = order).
- *Pozdrow!* taught as "Greetings!" is the imperative "greet!".
