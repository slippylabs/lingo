# slovenian-from-english: unsure / out of scope

## For the parent (affects all Slavic template courses, likely)
- EVERY mini-dictionary entry in the course is the literal string "undefined" (4289 entries). The export puts it
  in the hint lists, e.g. dict "zelo": ["undefined"], "jaz": ["I","undefined"]: learners see "undefined" as a hint.
  Best fixed in code (drop "undefined" glosses in the exporter/loader), not per entry. My new dictionary entries
  have real glosses.

## Plausible but left alone
- dom is taught as "house" throughout; it really means "home" (house = hiša). Adding "home" alternatives everywhere
  would be the fix.
- kostanjev taught as "brown"; it means chestnut-coloured (brown = rjav).
- drzen taught as "brave"; it means bold/daring (brave = pogumen).
- "bolj visok", "bolj lep", "bolj veliko" are taught as comparatives; standard is višji, lepši, večji. Skill is
  "easy comparisons" so kept.
- "On je z vilico." (He eats with a fork) reads as "He is with a fork" without the accent (jé).
- "Jaz kupim maslo." = "I will buy butter": present perfective; standard future is "Kupil bom maslo".
- Noun-phrase number drills use accusative ("štiri dolarje", "dvesto tri računalnike") while others are nominative.
- "Mirno noč!" for Good night (usual: Lahko noč!), "Vračilo je do sedem dni", "Ulica je dolga in topla",
  "Gremo na pohod" (= hike, English says walk): odd but not wrong enough to change.
- "bi bil" listed three times with different persons (conditional is the same form; fine but repetitive).
- English hints on number phrases ("zero clocks", "one thousand one clocks") are template-awkward.
