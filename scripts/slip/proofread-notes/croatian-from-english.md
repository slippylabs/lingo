# Croatian: unsure / not fixed

SYSTEMIC (all 16 Slavic courses): every mini-dictionary gloss is the literal string "undefined"
(4,338 in Croatian; 4,289-4,394 in each sibling). The exporter emits it as the hint, so learners see
"undefined" (or "mačka\nundefined") in word hints. Fix belongs in the exporter/web layer (drop
definitions equal to "undefined"), not 4k per-course edits. New entries added by my fixes carry real glosses.

Plausible but not fixed:
- characterconditional: "Kao što bi čuo, oni bi bili tihi." = "If you would hear, they would be silent." Croatian is muddled ("kao što" = "as"); probably meant "Kad bi čuo…". Needs a native rewrite.
- emotionsadverbs: "Trpjeti želimo samo kad volimo." = "We only suffer when we love." Croatian literally "we want to suffer only when we love".
- emotionsadverbs: Word "drhtanje/strah" = "tremor": drhtanje = trembling, strah = fear. Gloss half right.
- cardinalpointsdirections: "Sunce ustaje na istoku" - standard Croatian says "Sunce izlazi"; the Word "ustati = to rise" would need swapping too.
- cardinalpointsdirections: "region" is more Serbian; standard Croatian "regija".
- askingfordirections / citybuildings: "biblioteka" is Serbian-leaning; standard Croatian "knjižnica". Left (used across several files).
- greetings: "Dobar večer!" - standard is "Dobra večer"; "Dobar večer" is common colloquially. Left.
- professions: "svoju tvorbu" (his work) - "svoje djelo" is natural.
- drinksgenitivecase: genitive after negation ("ne pije vina", "nemam vode") is old-fashioned; modern speech uses accusative. Correct, left.
- familyinstrumentalcase: "kćer" as nominative is colloquial (standard kći). Left.
- fruits: "Grožđe raste na vinogradu" - usual is "u vinogradu".
- physicalappearance md still frames više as a comparison word; fine after the phrase fixes.
- Polish name "Bartek" and "Vlad", "Frank" kept.
